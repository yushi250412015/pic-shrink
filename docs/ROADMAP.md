# Pic Shrink 差异化路线图（ROADMAP）

> 轨道 A 文档。目标：把 Pic Shrink 从「又一个图片压缩工具」优化成**有清晰差异化定位的实用产品**。
> 更新时间：2026-08-16。

## 1. 市场对照与差异化定位

市面上「轻图」类工具（在线压缩站 / 轻量图片 App）普遍痛点：
- 要上传服务器 → 隐私顾虑、大文件慢；
- 功能单一（只压缩）或广告多；
- 批量/场景化能力弱，对创作者与学生不友好；
- 不开源、不可离线。

**Pic Shrink 的差异化四板斧：**

| 维度 | 竞品常见 | Pic Shrink 定位 |
|---|---|---|
| 隐私 | 上传服务器处理 | **文件永不出本地**（浏览器内完成，可断网验证） |
| 可用性 | 需联网、网页关了数据就没了 | **PWA 可安装、离线可用**，像本地 App |
| 效率 | 单张处理 | **批量 + 场景预设一键出图**（头像/封面/小红书/证件照等） |
| 开放性 | 闭源 | MIT 开源，可自建部署 |

**一句话定位**：`离线优先的隐私图片工坊 —— 批量压缩/转换/水印/PDF，图片不出你的电脑`。

## 2. 路线图

### 已发布（v1.0.0）
批量压缩、质量/目标大小双策略、JPG/PNG/WebP/AVIF 转换、旋转翻转裁剪、文字水印、GIF 优化、PDF 合并/拆分/提取/压缩、EXIF 查看与清除、ZIP 打包、中英双语、场景预设 8 个。

### 已发布（v1.1.0）
PWA 离线安装、暗色模式、前后对比滑杆、批量重命名模板、PDF 页面旋转/删除/重排、场景预设扩充至 16 个、持久化统计、快捷键。

### 已发布（v1.2.0）
HEIC/HEIF 解码、批量证件照排版、PNG 优化策略、图片转 PDF、极简模式、自定义场景预设。

### v1.1.0（已完成）
- [x] **PWA 离线安装**：manifest + Service Worker（缓存优先，离线可用、可安装到桌面）
- [x] **暗色模式**：跟随系统/手动切换，localStorage 记忆
- [x] **处理前后对比滑杆**：每张结果卡片 before/after 对比
- [x] **批量重命名模板**：`{name}/{index}/{date}/{ext}` 占位符（替代简单前后缀）
- [x] **PDF 页面操作增强**：旋转页面、删除页面、重排
- [x] **场景预设扩充**：微博/B站/知乎/抖音/GitHub 头像等（16 个）
- [x] **持久化统计**：历史会话、累计节省体积、处理张数
- [x] **快捷键**：打开/删除/关闭弹窗
- [x] GitHub topics、README 功能表更新、版本 1.1.0

### v1.2.0（已完成）
- [x] **HEIC/HEIF 解码支持**：heic2any 纯 JS，Worker 内解码为 JPEG 后进入现有管线
- [x] **批量证件照排版**：一寸/二寸拼 4×6 相纸，底色白/红/蓝、张数可调
- [x] **PNG 优化策略选择**：默认 / 有损（canvas 量化）/ 无损（oxipng wasm）
- [x] **图片转 PDF**：多图合并，每图一页（原图尺寸 / A4 适配居中）
- [x] **极简模式**：隐藏高级设置，只留格式 + 质量/目标大小 + 场景
- [x] **自定义场景预设**：场景下拉「我的预设」分组，可增删尺寸模板

### v1.3+（候选，按价值排序）
- [x] 长截图/拼接（横向/纵向拼接）
- [x] 元数据批量编辑（标题/作者，EXIF 写入，仅 JPEG）

## 3. 长期差异化实验方向

- [x] **学生/创作者友好**：投稿尺寸库（B站/知乎/公众号/小红书/微博/抖音，14 尺寸按平台分组）+ 一键套用 ✅（本轮完成；纯函数 `utils/submission-sizes.js`，来源/置信度入档 `docs/research/submission-sizes.md`）
- **可编程能力**：纯函数核心保持可测试、可被复用到 CLI/桌面端（Electron/Tauri）
- **无障碍与性能**：大图内存优化（分块处理）、处理进度可预测

## 4. 维护纪律（遵守工作区通用守则）

- 纯函数 utils 与 UI 分离，新逻辑必须带单元测试
- 语义变更同步 CHANGELOG；发布后检查 GitHub About/README/线上页面
- 每次交付：`npm test` 全绿 + `npm run build` 通过 + push（网络抖动用后台重试）

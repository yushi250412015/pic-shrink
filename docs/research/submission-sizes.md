## 说明

- 以上均为「社区/官方公开资料」，非逐条官方白纸黑字的原始规范；已尽量交叉印证，但**置信度未到「官方实测」**，故在数据中保留 `source` 链接供回溯。
- 平台显示端常对图片做压缩/裁剪（如公众号首图会被折叠、小红书 3:4 首图会被裁角标），本库只保证「输出的宽高比与像素」，不保证平台最终渲染效果。
- 若后续要做「投稿尺寸库」的更权威版本，建议逐平台抓取官方创作者中心/帮助中心最新数值，并把置信度升级为「官方资料」。

## 实现要点

- 数据与纯函数分离：`SUBMISSION_SIZES`（数据）+ `findSubmissionSize` / `submissionSizesFor` / `resolveSubmissionSize`（纯函数）。
- 一键套用复用现有「场景预设」的 cover 裁剪管线（`compression.js` 中 `findSubmissionSize` 参与场景解析），无需新增 Worker 逻辑。
- UI 分组：场景下拉中按平台分组显示「投稿尺寸库」，选项 title 显示精确像素。
- 自定义预设去重：`filterOutBuiltin` 同时排除与内置场景/投稿尺寸重复的自定义项。
